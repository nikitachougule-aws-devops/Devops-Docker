# Devops-Docker

A comprehensive Docker learning repository covering Docker fundamentals, installation, commands, Dockerfiles, volumes, networking, Docker Compose, and interview preparation.

## 📚 Repository Contents

| File | Description |
|--------|------------|
| 01. introduction.md | Introduction to Docker and containerization concepts |
| 02. installation of docker.md | Docker installation guide for different operating systems |
| 03. docker commands.md | Frequently used Docker commands with examples |
| 04. dockerfile.md | Understanding Dockerfiles and image creation |
| 05. docker volumes.md | Persistent storage and Docker volumes |
| 06. docker networking.md | Docker networking concepts and configurations |
| 07. docker compose.md | Multi-container applications using Docker Compose |
| 08. Docker Interview Questions.docx | Docker interview questions and answers |
