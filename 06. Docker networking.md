## Docker Network

- Docker Network is a feature that allows Docker containers to communicate with each other and with external systems.
- It allows containers on the same network to communicate securely using container or service names.

## Example

Suppose you have:

- A web application container
- A database container

The web application needs to fetch and store data in the database.
```bash
Web Container  <--->  Database Container
```
Docker Network provides the connection between them.

## Why is Docker Network Needed?
- Enables communication between containers
- Allows containers to access external services
- Provides isolation and security
- Automatically handles container name resolution

## Docker Network Types

1. Bridge Network
- Default network for containers running on a single host.
```bash
docker network create mynetwork
```

2. Host Network
- Container shares the host machine's network.
```bash
docker run --network host nginx
```

3. None Network
- No network access.
```bash
docker run --network none nginx
```
