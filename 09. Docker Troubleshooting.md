## Docker Troubleshooting

## 1. Docker Daemon Is Not Running

### Error

```text
Cannot connect to the Docker daemon.
```

### Cause

The Docker service is stopped.

### Solution

Start Docker Desktop or the Docker service.

Verify:

```bash
docker version
```

---

## 2. Port Is Already Allocated

### Error

```text
Bind for 0.0.0.0:8080 failed:
port is already allocated
```

### Cause

Another application or container is already using the port.

### Solution

Check running containers:

```bash
docker ps
```

Stop the conflicting container:

```bash
docker stop <container_id>
```

Or run the container on another port.

---

## 3. Image Not Found

### Error

```text
Unable to find image
```

### Cause

The image does not exist locally.

### Solution

Pull the image:

```bash
docker pull nginx
```

---

## 4. Container Exits Immediately

### Error

Container starts and stops instantly.

### Cause

The main application inside the container has finished or crashed.

### Solution

View logs:

```bash
docker logs <container_name>
```

Fix the application error and restart the container.

---

## 5. Permission Denied

### Error

```text
permission denied
```

### Cause

Insufficient permissions to access Docker.

### Solution

Linux:

```bash
sudo docker ps
```

or add your user to the Docker group.

---

## 6. No Space Left on Device

### Error

```text
no space left on device
```

### Cause

Unused Docker images, containers, or volumes consume disk space.

### Solution

Remove unused resources:

```bash
docker system prune
```

---

## 7. Build Failed

### Error

```text
COPY failed
```

### Cause

Incorrect file path or missing file.

### Solution

Verify:

* Dockerfile location
* File paths
* Build context

---

## 8. Cannot Access Application

### Problem

Application is running but cannot be accessed.

### Cause

Incorrect port mapping.

### Solution

Verify:

```bash
docker ps
```

Example:

```bash
docker run -p 8080:80 nginx
```

Access:

```text
http://localhost:8080
```

---

## 9. Docker Compose Service Cannot Connect to Database

### Cause

Wrong hostname.

### Incorrect

```text
localhost
```

### Correct

Use the service name.

```text
mysql
```

Docker Compose automatically creates a network for services.

---

## 10. Volume Changes Not Reflected

### Cause

Incorrect volume mapping.

### Verify

```bash
docker volume ls
```

Check volume configuration in `docker-compose.yml`.

---

## Useful Debugging Commands

```bash
docker ps

docker ps -a

docker images

docker logs <container>

docker inspect <container>

docker exec -it <container> bash

docker network ls

docker volume ls

docker system df

docker system prune
```

## Docker Troubleshooting Workflow

```text
Application Not Working
          │
          ▼
Check Container Status
          │
          ▼
docker ps
          │
          ▼
Container Running?
     │            │
    No           Yes
     │            │
Check Logs   Check Port Mapping
     │            │
     ▼            ▼
Fix Error    Test Application
     │
     ▼
Restart Container
```

---

## Best Practices

* Check container logs before making changes.
* Verify port mappings and exposed ports.
* Use official Docker images whenever possible.
* Keep Docker images updated.
* Clean unused images and containers regularly.
* Test Docker Compose services individually before deploying.
