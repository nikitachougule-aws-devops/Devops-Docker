## Docker Compose

- It is a tool used to define and manage multiple Docker containers using a single YAML configuration file (docker-compose.yml or compose.yaml).
- We define services, networks, and volumes in a compose.yaml file and use commands like docker compose up and docker compose down to manage the entire environment.

## Example

Suppose your application needs:

1. Frontend container
2. Backend container
3. Database container

Without Compose:
```bash
docker run frontend
docker run backend
docker run postgres
```
With Compose:
```bash
services:
  frontend:
    image: frontend

  backend:
    image: backend

  db:
    image: postgres
```

Start everything with:
```bash
docker compose up
```

## Why Use Docker Compose?
- Manage multiple containers together
- Single configuration file
- Easy setup and deployment
- Automatic network creation
- Automatic volume management
- Consistent environments

## What Happens When You Run docker compose up?

Docker Compose:

- Creates required networks
- Creates required volumes
- Builds images (if needed)
- Starts all containers
- Connects containers together

## 🔹 Basic Structure (`docker-compose.yml`)

```yaml
version: "3"

services:
  web:
    image: nginx
    ports:
      - "8080:80"

  db:
    image: mysql
    environment:
      MYSQL_ROOT_PASSWORD: example
```

| Section | Configuration | Simple Meaning |
|----------|--------------|---------------|
| Version | `version: "3"` | Docker Compose file version. |
| Services | `services:` | List of containers to create. |
| Web Service | `web:` | Creates a web server container. |
| Web Image | `image: nginx` | Uses the Nginx web server image. |
| Port Mapping | `ports: "8080:80"` | Open website on localhost:8080. |
| Database Service | `db:` | Creates a database container. |
| Database Image | `image: mysql` | Uses the MySQL database image. |
| Environment Variables | `environment:` | Sets configuration for the container. |
| MySQL Root Password | `MYSQL_ROOT_PASSWORD: example` | Sets the MySQL root password. |
| Network | Automatic | Connects web and db containers together. |
| Service Communication | `db:3306` | Web app can talk to MySQL using the name db. |
| Start Command | `docker compose up -d` | Start all containers. |
| Stop Command | `docker compose down` | Stop and remove all containers. |

What this file does:

- This Docker Compose file creates two containers: an Nginx web server and a MySQL database. Docker automatically connects them through a network, exposes the web server on port 8080, and configures MySQL with a root password. Both services can be started together using docker compose up -d.
